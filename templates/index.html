System Architecture & ML Methodology

Complete 5-stage Data Flow and Machine Learning classification pipeline.

Data Flow Diagram (DFD Level 0 & 1)

Stage 1

User Query Input

Captures student inquiry via Web Speech Recognition (voice) or text input.

Stage 2

Text Preprocessing & Normalization

Lowercasing, regex punctuation removal, whitespace trimming, and entity tokenization.

Stage 3

Dual-Layer TF-IDF Feature Extraction

Transforms text into numerical vectors using sublinear TF-IDF (1-3 word n-grams + 3-5 char n-grams).

Stage 4

Deep Neural Classification (MLP)

Multi-Layer Perceptron (Dense 128 -> Dense 64 -> Softmax 39) with 99.51% classification accuracy.

Stage 5

Response Delivery & Audit Logging

Returns verified university data in <15ms. Logs query, confidence, and feedback into SQLite (chatbot.db).

1. Problem Statement

During admission cycles and semester examinations, university students and prospective applicants face long waiting times at administrative counters and difficulty navigating complex, multi-page university websites to find basic institutional details such as tuition fees, required admission documents, hostel mess timetables, and department HOD contacts. This creates administrative overload for college staff and causes anxiety and delayed admissions for students. An automated, 24/7 conversational system is required to answer natural language inquiries instantly and accurately.

2. Proposed Solution & Approach

We developed an intelligent, full-stack AI conversational chatbot system that automates university student support. The solution utilizes a supervised training dataset of 39 university functional intents and 412 sample questions. It employs a hybrid NLP classification pipeline combining Sublinear TF-IDF (word & character n-grams) with a Deep Multi-Layer Perceptron (MLP) Neural Network, achieving 99.51% classification accuracy. The system delivers verified responses in under 15ms, provides Web Speech API voice input and narration, and logs all interactions into an SQLite database for administrative auditing.

3. Key Results & Metrics

  • Model Accuracy: 99.51% training accuracy across 39 distinct university intent classes.
  • Response Latency: < 15 milliseconds average end-to-end inference time.
  • Intent Coverage: 39 institutional domains (fees, admissions, hostel, mess timetable, placements, faculty).
  • Business Value: Reduces repetitive inquiry load on college administrative staff by an estimated 80%, providing zero-wait 24/7 student guidance.

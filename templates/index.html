Project Architecture & Methodology

Technical workflow and algorithms implemented in this final year capstone project.

Machine Learning Pipeline Block Diagram

Step 1

Text Preprocessing

Lowercasing, punctuation removal, regex cleaning, and whitespace normalization.

Step 2

Dual-Layer TF-IDF Feature Extraction

Generates Sublinear TF-IDF word vectors (1-3 n-grams) and character vectors (3-5 n-grams) for typo resilience.

Step 3

Deep Neural Network Classifier

Multi-Layer Perceptron (Dense 128 -> Dense 64 -> Softmax 39) trained for 350 iterations with Adam optimizer.

Step 4

Hybrid Ensemble & Disambiguation

Blends 65% Neural probabilities with 35% TF-IDF Cosine Similarity, plus departmental entity matching (e.g. Computer vs IT HOD).

Step 5

Calibrated Response Delivery

Delivers verified answers, formatted tables, and smart suggestions in under 12ms. Logs interaction to SQLite.

Project Synopsis & Academic Details

Official submission synopsis for Final Year B.Tech Engineering Examination.

DEPARTMENT OF COMPUTER ENGINEERING

Bachelor of Technology (B.Tech) • Final Year Capstone Project

1. Problem Statement

During admission cycles and semester examinations, university administrative offices face thousands of repetitive inquiries regarding fee structures, syllabus, timetables, and hostel facilities. Traditional static web portals result in long wait times. This project addresses the challenge by implementing an intelligent, 24/7 conversational NLP system capable of answering student queries accurately in real-time.

2. Key Project Objectives

  • Develop a supervised intent dataset covering 39 critical university functional domains.
  • Build a hybrid classification architecture combining Sublinear TF-IDF (word & character n-grams) with a Deep Multi-Layer Perceptron (MLP) Neural Network.
  • Achieve greater than 98% classification accuracy with sub-15ms response latency.
  • Implement Web Speech API for voice-driven student accessibility.
  • Provide real-time query logging and administrative review for continuous learning.
